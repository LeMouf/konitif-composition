# Starting point

Composition 0.284.1 begins its independent preparation with workflow and
composition contracts, validation helpers and a commit boundary that accepts
valid candidates and preserves the previous workflow when a candidate fails.

The source is extracted as a package-only snapshot. No mixed development
history, application code or company assets are included. Public interfaces
and version are retained; relative ESM imports and standalone TypeScript
configuration support direct Node consumption.

This baseline is not an npm publication or a release of the KONITIF ecosystem.
